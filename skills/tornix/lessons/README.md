# Lessons — self-improvement loop

Every pitfall, user correction, or discovered workflow gets a dated entry here.
A curation pass (manual or periodic) promotes proven lessons into SKILL.md.

## How to add a lesson
Append a new entry: `YYYY-MM-DD — <title>` + what happened + the fix/rule.
Keep it short (2-4 lines). One file per month: `lessons/2026-08.md`.

## How lessons get promoted
- A lesson is "proven" after it has been applied successfully 2+ times (or
  caused a user correction once).
- Proven lessons move into the relevant SKILL.md section (curated, not dumped).
- The lessons file keeps the history; SKILL.md keeps only the active rules.

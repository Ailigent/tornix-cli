# `tornix api credit-hub` — 4 commands

- `tornix api credit-hub delete --json` — Stop reporting this organisation to the hub
- `tornix api credit-hub links --json` — Which organisations report to the credit hub
- `tornix api credit-hub links-create --json` — Link an organisation to a company on the hub
- `tornix api credit-hub sync --json` — Run a sync round now instead of waiting for the minute
